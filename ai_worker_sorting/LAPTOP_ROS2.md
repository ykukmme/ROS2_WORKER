# 이전 Windows 웹캠 실험

Windows 웹캠 → HTTP 브리지 → Humble Docker 실험은 [보관 문서](../docs/archive/WINDOWS_WEBCAM.md)에 있다.
실행 상태·컨테이너명·임시 경로는 작성 당시 개발 환경의 기록이다.

현재 공용 Ubuntu PC는 Jazzy 이미지를 사용하며 AI WORKER의 실제 RGB-D 토픽을 구독한다.
Windows 브리지나 `host.docker.internal` 설정은 현재 기본 실행 절차에 포함하지 않는다.
현장 실행은 [공용 PC 안내](../docker/SHARED_PC.md), 카메라 전제는 [실물 연결](LIVE_ROBOT.md)을 따른다.
